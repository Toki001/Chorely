# M06 — Family membership and supervised devices

Status: PASS for local membership/supervised-device gate. Date: 2026-10-29, branch main.
Dependency: M05 85f7c0e. Commit recorded after verification in PROGRESS.

Implemented recipient-bound adult/guardian invites; expiry, single consumption,
revocation and payload-bound retry receipts. Guardian removal preserves an active
guardian and removes discovery access atomically. Child profiles collect nickname
and generic avatar only. Guardian approval issues a ten-minute code; signed-out
device claims it with a separate retry proof and receives scoped custom Auth.
Each device UID resolves to a stable profile actor through current membership.

Guardian/adult/child UI differs by real account and membership. Child mode has no
adult mutations and adult credentials are required to return on a shared device.
QR render/copy and on-demand scanning have manual code fallback. Auth identity
changes discard routes/overlays and pending stale claim responses. Codes show
server-provided expiry and stop presenting the QR/copy action when expired.
Exact policy, limits and security boundaries are in ADR-003.
