## Delivered behavior

`features/sync` adds a SQLite command journal and bounded confirmed read cache.
Completion, undo, help, approval, redo and help resolution persist their immutable
UUID, SDK UID, occurrence, base and payload before sending. Restarts retry the
same request. Unknown responses stay pending; known conflict/rejection stops
replay and requires a successful current server read before explicit review.
Only stored occurrences drive completion/progress. Accepted local receipts
fence old snapshots against a second tap.

Confirmed home/index, membership/role, roster, chore/range and clock DTOs are
cached by SDK UID and household, with a supervised-profile key and household
scope fence. Firestore memory snapshots never establish fresh authority. Minimal
session fallback copies no email/token and works only for the SDK's same current
UID on a network-only claims lookup failure. Restoration suspends replay without
deleting isolated bytes. Logout/identity change purges old data. Known denial or
confirmed home-index removal purges the household and blocks late new requests.
Native database epochs fence queued writes during purge.

The saved-data/pending/review area preserves navigation and scrolls at large text.
Signing out with requests waiting explains removal of the device queue. Private
help notes and privileged activity are not read-cached. Household/chore/rule/
preference authoring still requires a connection. iOS uses a backup-excluded
protected directory; Android disables app backup. SQLite uses FULL sync,
secure_delete and DELETE journals. This is OS storage protection, not application
encryption or a forensic-erasure guarantee. ADR 009 records bounds and policies.

## Failures fixed

Darwin's secure_delete pragma returns a row; rawQuery fixes the initial rowless
execute error and verifies protection is enabled. The failure correctly prevented
false saved-success. Native conflict assertions now wait for the previous route
to disappear. Offline indeterminate loaders cannot pumpAndSettle; helpers wait
for exact real data and advance finite route/scroll animations. A 52-pixel status
overflow at 320dp/200% is fixed with bounded scrolling and an explicit body style.
The final analyzer also caught and fixed a missing conditional brace. Passing
reruns, rather than those failed attempts, support acceptance.
